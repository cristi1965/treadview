# 死页面审计闭环（2026-09-08）

## 范围与判定

本轮按 `specs/dead-page-audit-loop.md` 审计 32 个代表性路由，覆盖历史研究 + Paper 主产品、
StockGod 实验行情、动态详情、查询参数、静态页与 404。桌面视口为 `1440x1000`，移动视口为
`390x844`。页面空白、错误边界、5 秒后仍只有加载态、关键目标内容错误、横向溢出或无恢复的
主操作均判为产品失败。

外部数据陈旧或不可用不自动判为死页面；只有在页面明确 fail-closed，显示来源/时间/原因，
并保留历史内容、规则内容、重试或修复入口时才允许通过。

## 修复摘要

- 所有共享 API 请求最多 5 秒进入成功或错误终态；复盘、宏观与国会详情不再绕过超时。
- Notes、Whales、国会详情和写入失败失败均保留当前输入/上下文，并提供重试或返回入口。
- 报告详情切换时先清除旧报告和旧 freshness，避免 URL 指向 B 却继续展示 A。
- ETF 历史接口继续返回 `X-Data-Stale: true` 和真实快照日期，不把旧数据伪装成实时。
- ETF 对比增加加载、错误和重试状态；局部失败不再表现为按钮无响应。
