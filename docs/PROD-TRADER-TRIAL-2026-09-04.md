## GitHub 方案对照

- `philippdubach/vol-regime-prediction` 的做法是 CBOE + FRED + 行情源分域采集，并对 VIX、期限结构、Put/Call 等特征分别记录覆盖范围；本项目已采用其中的分源原则。
- `violettance/etf-dashboard` 的做法是维护有限、可审计的 ETF universe，把费率/成立日作为带验证日期的参考数据，把价格/波动/回撤作为实时数据；缺失字段不填 0，而是显示覆盖率。
- `yieldchaser/etf-data` 的做法是发行人页面抓取、每日快照、历史归档和失败隔离；这比一次性生成 4533 条无来源分析更适合生产。
- `isaergun/etf-flows-data` 提供 GitHub Actions 定时更新 AUM/份额/流量的思路，但当前运行环境拉取 raw 文件超时，不能直接作为本地实时源。
- `CBOE VIX History` 当前可访问，`CBOE` 旧 Put/Call CSV 只到 2019-10-04；因此情绪现在明确返回 CBOE VIX/FRED 利率的 `asOf`，其余没有同日来源的字段继续标 stale。
