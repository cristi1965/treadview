## 角色视角摘要

1. **投资与研究视角**：事实底稿、趋势、风险诊断和用户敏感性已经可用于复核；不把单一情景包装成预测。下一阶段可补 PIT 同行、现金流和三情景矩阵。
2. **交易与风险视角**：Paper 生命周期、partial fill、OCO、逐笔日内 P&L、币种隔离和 baseline 防篡改闭环；仍明确是进程内模拟，不是券商托管订单。
3. **用户与合规视角**：移动端路径、结构化持仓和研究到 Paper 的边界清楚；ticker/run ID 可传递，但方向、数量、价格和止损不会继承。
4. **生产运维视角**：源码测试、race、独立二进制、API 门禁与桌面/390px 浏览器证据一致；外部行情瞬时失败会阻断或重试，不会伪装成功。
