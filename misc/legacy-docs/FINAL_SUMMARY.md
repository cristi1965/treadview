## 🌟 核心特性

### 1. 五方评分系统
**创新点**: 多维度股票评分
- 巴菲特：价值投资视角
- 段永平：长期持有视角
- 宁静致远：低波动视角
- Druckenmiller：宏观趋势视角
- 市场情绪：社交媒体情绪

**可视化**: 五边形雷达图（SVG）

### 2. Canvas 力导向图热力图
**创新点**: 983 个股票实时可视化
- D3.js Force Simulation 算法
- Canvas 高性能渲染
- 颜色编码涨跌
- 大小编码市值
- 交互式 Tooltip

**性能**: 30-60 FPS 稳定运行

### 3. ETF 板块分析
**覆盖**: 47 个板块，8 个类别
- 宽基、行业、主题、策略
- 风格、商品、债券
- 管理规模、回撤分析

### 4. 股票对决系统
**功能**: 双股票可视化对比
- 自动补全搜索
- 双雷达图对比
- 赢家高亮
- 指标对比

### 5. Markdown 盘报
**内容**: 盘前看点 + 收盘复盘
- 市场日历集成
- Markdown 渲染
- 展开/折叠
- 加载更多
