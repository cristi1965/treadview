# 我不是神 · 浏览器插件 (Chrome / Edge Extension)

> 🚀 在 **TradingView 官方网站**、**雪球**、**Yahoo Finance** 等任意看盘页面直接获取 **五神打分**、**AI 支撑阻力位** 与 **此刻买入决策**！

---

## 📦 10 秒安装指南

1. 打开 Chrome / Edge / Brave 浏览器，在地址栏输入：
   ```text
   chrome://extensions/
   ```
   *(Edge 浏览器输入 `edge://extensions/`)*

2. 打开右上角的 **「开发者模式」(Developer Mode)** 开关。

3. 点击左上角的 **「加载已解压的扩展程序」(Load Unpacked)**。

4. 选择本项目目录下的文件夹：
   ```text
   /Applications/workspace/ai管力/账本/TradingAgents/app/extension
   ```

5. 完成！在浏览器右上角插件栏即可看到 **👑 我不是神** 图标！

---

## ✨ 核心能力

1. **悬浮 HUD 胶囊 (Floating Pill)**：
   在浏览 `TradingView.com` 任何图表或 `雪球` 个股页时，页面右下角自动浮现当前标的的 **AI 评分胶囊**，点击即可展开多空支撑阻力位与操盘建议。

2. **浏览器弹窗独立速查 (Popup Dashboard)**：
   点击浏览器右上角扩展图标，随时随地输入股票代码（如 `NVDA`, `TSLA`, `300750`），秒级获取五神综合评分。

3. **双向一键跳转**：
   从插件可一键直达本地运行的 **四分屏盯盘工作台 (`/multichart`)** 与 **驾驶舱 10-Agent 深度研判**。
