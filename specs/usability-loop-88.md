# 核心可用性 Loop 88

## 目标

用真实浏览器任务验证 TradingAgents “能用起来”，固定量表总分达到 88 以上。页面可渲染只是前置条件，不等于任务通过。

## 固定任务

1. 设置：本机会话能自动建立，用户能看懂 historical-research、Paper 和 live 的独立门禁。
2. 研究：驾驶舱的仅证据研究入口可操作，失败时必须显示未保存原因和恢复入口。
3. 交接：历史记录可进入 Paper，只传 ticker 与 run ID，不暗中传买卖方向。
4. Paper：能读取独立账户、报价与风控状态；条件不满足时禁止提交并给出具体原因。
5. ETF/A 股工具：`/etf#cn-tools` 必须直接显示工具区，查询或数据失效均有明确结果。
6. GPU：动态报价可用时能筛选和看历史；未配置时禁用上游刷新，显示配置原因和独立官方参考价。

每条任务在桌面 `1440x1000` 与手机 `390x844` 中验收。

## 固定量表

| 维度 | 权重 |
|---|---:|
| 任务完成度 | 35% |
| 结果正确性 | 20% |
| 失败恢复性 | 15% |
| 状态反馈 | 10% |
| 移动端可用性 | 10% |
| 操作效率 | 10% |

任一 P0（伪造数据、越权写入、可误触真实交易）将整轮封顶为 59。任一核心任务无结果且无恢复入口将整轮封顶为 79。

## 证据

每轮保存 JSON 和任务截图到 `output/playwright/usability-rN/`，记录 URL、操作前后状态、网络失败、console/page error、横向溢出与总耗时。
